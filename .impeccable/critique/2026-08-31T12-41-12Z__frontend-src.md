## Anti-Patterns Verdict

**LLM:** Wizard and auth no longer look like a template. `/` and product landings still do. Identity paint (Sora/teal) is on; the layout grammar is still catalog + eyebrows + equal cards + stats. Divorcio360 is light now, not `#0d0f0d`, but the first screen is still a 100dvh slogan with GSAP opacity-0 words and no in-hero CTA.

**Detector:** 11 warnings, 1 rule (`broken-image`). All Angular `[src]` bindings. False positives: home hero images paint. Inter/Fraunces not loaded. `100vh` = 0 hits, `100dvh` = 3–6. Wizard/auth footer is 1 row; marketing/404 is 4-col.

**Overlays:** Not injected (Cursor browser MCP did not stay registered). Fallback: Playwright + a11y/CSSOM on five routes.

## Overall Impression

The identity lock worked. The score moved because chrome, type, 404, and compact footer are now one system. The score did not jump into Good because `/` still hides the live trámite behind a seven-product mall, and Divorcio360 still spends a viewport on theater before a button.

Biggest remaining opportunity: one **Comenzar** with one object (`/cuestionario`), and a Divorcio hero that starts the trámite above the fold.

## What's Working

1. **Identity lock.** Sora only in `index.html` + computed fonts. `--brand` teal on CTAs. Skip-link first Tab. Per-route titles (`LegalStation`, `Divorcio360`, `Cuestionario · Divorcio360`, `Ingresar · LegalStation`, `Página no encontrada · LegalStation`).
2. **Wizard as a task.** One question, progress, review, legal disclaimer, compact footer. This is the only surface that matches *preciso, sereno, operacional*.
3. **Exits exist.** Auth labeled `Correo`/`Contraseña`. 404 stays on `/ruta-falsa-xyz` (HTTP 200 SPA) with *Esta página no existe* + Volver. Copyright string unchanged: `© 2026 CodiDevs · Demo LegalStation`.

## Priority Issues

- **[P1] Comenzar is three actions on `/`.** Header/hero → `#catalogo`. Dark-island → `/productos/divorcio360`. Footer → `/cuestionario`. Catalog says six products, grid has seven. Four cards toast instead of opening a flow.
  - Why: Jordan's first click is a mall, not intake. PRODUCT.md success test fails.
  - Fix: Primary CTA `Comenzar Divorcio360` → `/cuestionario`. Catalog secondary. Mark non-live tiles.
  - Suggested command: `/impeccable distill` on `saas-landing.component.ts` + `marketing-hero.component.ts`

- **[P1] Divorcio360 first viewport is slogan theater.** Light teal now, but `100dvh` intro, `.reveal-word` at `opacity: 0`, no in-hero CTA, heading not an `h1` in the DOM (first heading is H3 *Expediente Divorcio360*).
  - Why: Casey never reaches the questionnaire. Visual users get a blank hero until GSAP.
  - Fix: Visible H1 + Comenzar → `/cuestionario` above the fold. Motion as enhancement, not a visibility gate.
  - Suggested command: `/impeccable quieter` on `hero-scroll-video-pin-reveal.component.ts`

- **[P1] Wizard commits without Back; Sí looks correct.** `answer(true|false)` advances immediately. Sí is filled teal; No is ghost. Pills wrap on 390px and are not clickable.
  - Why: One mis-tap is recall until review. Color+weight bias the legal answer.
  - Fix: Equal Sí/No. Atrás on every step. Pills as controls or drop them.
  - Suggested command: `/impeccable harden` on `questionnaire.component.ts`

- **[P2] Marketing still ships the banned kit.** Eyebrows (`lp-eyebrow`, `hsvr-intro-eyebrow`), `app-landing-statistics` hero-metrics (`120+`, `$349`), 7 identical product cards, dark `.lp-cta-inner` island, gallery glass, Georgia `tone-serif` in logo cloud, leftover `#d8d2ca` / `#eef0fb`.
  - Why: Identity work does not survive a scroll. Still reads AI-made.
  - Fix: One proof (honorarios or 10 estados). No fake firm count. No stat grid as hero furniture.
  - Suggested command: `/impeccable quieter` + `/impeccable typeset`

- **[P2] Product sites leak a second brand in data.** `product-sites.data.ts` still has `accent: '#4a7eb8'` / `'#8b6b4a'`. Traslado CTA *Iniciar trámite →* vs header *Comenzar*. Footer copy on product pages still mentions divorcio notarial.
  - Why: Principle 1: landings do not invent accents.
  - Fix: Accents from tokens only. One CTA verb.
  - Suggested command: `/impeccable colorize` (restrain) on `product-sites.data.ts`
