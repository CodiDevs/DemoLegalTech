## Priority Issues

**[P1] Home is still two 7-item product walls**
- **What:** Tool pills + catalog cards for Divorcio360, Traslado360, BienRaiz360, SignDesk, MatterFlow, ComplianceHub, NotaryLink.
- **Why it matters:** Stakeholder cannot tell the live trámite from a platform module. Cognitive load sits here, not in the wizard.
- **Fix:** One row of three live trámites. Modules go behind a single “Plataforma” note, not a second identical grid.
- **Suggested command:** `/impeccable distill` on `saas-landing.component.ts`

**[P1] Traslado (and the product-site clone) is still an AI landing**
- **What:** Six uppercase eyebrows, Unsplash as “Pantallas reales del flujo,” invented testimonials, numbered six-up, disabled “Evaluación previa.”
- **Why it matters:** A tired user in a bufete will not trust a notary product that fakes screens and quotes. Demo-honesta is broken here even after polish.
- **Fix:** Kill eyebrows except maybe pricing. Replace gallery with real UI or drop the “reales.” Label quotes as escenario demo or cut them.
- **Suggested command:** `/impeccable quieter` + `/impeccable clarify` on `product-landing.component.ts`

**[P1] Divorcio still performs metric theater**
- **What:** Six stat cards: `24/7`, `1 click`, `3 días`, `+100%` on “Estados trazables,” plus a logo cloud of fake firm names under “Confianza de firmas y familias.”
- **Why it matters:** Polish removed the 120+ vanity set. This remainder is the same sin at smaller scale. Honorario `$349` and `10` estados are honest; the rest is not.
- **Fix:** Keep 10 estados, `$349`, maybe intake time. Cut trend pills and invented logos.
- **Suggested command:** `/impeccable distill` on `divorcio-landing.component.ts`

**[P2] Auth errors are visible, not operable**
- **What:** Submit works. Error is a red `<p class="err">` with no `role="alert"`, `aria-invalid`, `aria-describedby`, or `required`. Down-API copy names puerto 8080.
- **Why it matters:** Sam never hears the error. Jordan gets a developer sentence.
- **Fix:** Native `required`, bind error to fields, `aria-live="polite"`. Human copy for network failure.
- **Suggested command:** `/impeccable harden` on `auth.component.ts`

**[P2] Mobile chrome still fights Casey**
- **What:** Home/404 `scrollWidth` 400 vs 390. Header reports overflow. Wizard step 4 **Identidad** clips; pills are `nowrap` + `overflow-x: auto`.
- **Why it matters:** Thumb user on a Quito phone. Progress that hides the last step is a map the user cannot read.
- **Fix:** Tighten `mk-bar` at 390. Let steps wrap or become a compact “1/4 Elegibilidad.”
- **Suggested command:** `/impeccable adapt`
